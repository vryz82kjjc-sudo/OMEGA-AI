6 FUENTES

Qué hace TinyFish aquí

El motor tiene preparada una conexión de investigación web con TinyFish para fuentes públicas permitidas. No está activa sin una clave API del propietario, autenticación de administrador y autorización explícita para usarla.

Estado: Comprobando
No se puede leer de forma automática un anuncio de Idealista o Fotocasa por el mero hecho de pegar su enlace. Hay que respetar sus términos y las autorizaciones aplicables.

Flujo seguro

  1. El comprador pega el texto del anuncio o sus datos.
  2. Los módulos calculan y detectan información incompleta.
  3. Se contrastan fuentes oficiales y referencias autorizadas.
  4. El auditor revisa la evidencia y comunica las limitaciones.
  5. Solo el comprador decide si se negocia o comparte información.
